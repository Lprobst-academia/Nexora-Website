# Nexora Arcade — Version 4.1

A React + TypeScript + Vite prototype for an immersive virtual game store.

## Gameplay previews

Each featured title has a distinct playable browser mini-game with its own objective and short instructions:

- **EVO Racing — Night Circuit:** steer between three lanes, avoid traffic, collect boost cells and reach 1,500 metres.
- **Shadow Protocol — Ghost Network:** navigate a security maze, recover three data fragments and reach the uplink while avoiding patrols.
- **Kingdoms — Frontier Steward:** gather wood, stone and food, then build three homes while keeping the settlement supplied.
- **Deep Space — Orbital Salvage:** pilot through drifting debris and recover eight energy cores.
- **Pixel Worlds — Blockworks:** rotate and place falling shapes to clear five rows.
- **Nightfall — Lanternkeep:** explore a twilight maze, light five lanterns and reach the garden gate.

## Controls

- Showroom: WASD / arrow keys to move, mouse to look, **E** to open a nearby game. On touch devices, use the on-screen movement pad and drag to look.
- Racing: A/D or left/right arrows; hold Space for boost.
- Stealth and Nightfall: WASD / arrow keys.
- Kingdoms: choose the four resource/build actions below the game canvas.
- Deep Space: WASD / arrow keys; Space for a short dash.
- Pixel Worlds: left/right to move, down to soft-drop, up to rotate, Space to hard-drop.

## Notes

This is a prototype. Checkout is simulated, purchases and store customizations are stored in the current browser, and the demos are original compact arcade experiences rather than full commercial releases. No real payments are taken.

## Run locally

```bash
npm install
npm run dev
```
